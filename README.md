# PlanIA

Aplicación de planificación académica y de tiempo. Detecta bloques libres en tu semana y asigna
sesiones de estudio y trabajo profundo priorizando por urgencia e importancia.

Proyecto personal de Jorge, estudiante de Ingeniería de Software (UTP, Lima, Perú) — resuelve su
organización real entre clases (UTP + ICPNA), trabajo y proyectos, y sirve como pieza de portafolio.
